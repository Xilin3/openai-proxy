# BPS Excel CPA Native Plugin v0.2.0

- 复用 CPA 已有的、落盘的 Codex OAuth 凭据，不再新增 `bps-excel` 凭据。
- 保留原模型名和响应模型名，去掉 `-excel` 后缀。
- 启用后全局接管模型推理请求，进入 Excel 后端；不支持或失败时明确报错，
  不自动回退到原生 Codex 或其他 provider。
- 保留 CPA 原生登录及后台刷新；每次请求读取当前凭据，消费刷新后的文件。
- 修复 v0.1.0 缺少必需仓库元数据、无法在实际 CPA 宿主中注册的问题。

## 升级

替换 `.so` / `.dll`，合并配置示例并重启 CPA，客户端模型名删去 `-excel`。
原有 `type: codex` 凭据不修改；旧的 `type: bps-excel` 文件不再使用。
本插件应为最高优先级的模型路由插件，禁用竞争的全局路由插件。

## 验证与限制

27 项 Go 测试、双平台竞态检测、双平台动态库 ABI 测试及实际 CPA Linux
插件宿主测试通过。尚未连接真实账号、请求真实 BPS 上游或部署到用户服务器。

适配 CPA v8 / ABI 1 / schema 6；Linux amd64 产物要求 glibc 2.34+。
不支持 Home 模式、纯内存凭据或 API Key 代替 OAuth。凭据复用不等于接入
原生推理调度器，也不主动触发 401 后的刷新重试。仅使用 CPA 全局代理，
带独立 `proxy_url` 的账号会跳过。完整边界和 SHA-256 见随附说明及验证记录。
